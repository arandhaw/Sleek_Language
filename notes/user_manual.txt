This is a quick guide to sleek syntax. 

Comments: 
# this is a comment
#( this is a multi-line comment )#

# sleek is case sensitive
# sleek ignores whitespace, except for enter \n which implies the end of a line

# Everything starts from the main function
func main(){
    <statement 1>  # enter imples end of statement 
    <statement 2>; # semicolon ends statement - optional
    <statement 3>; <statement 4>; <statement 5>;   # multiple statements on the same line using semicolon
}

# other functions can be defined
# order of definitions in the global space doesn't matter
func my_name(<type> <input>, <type> <input>) -> <output type> { ... }

# if output type is none, specifying return type is optional
# these two are equivalent
func my_name(...) -> none {}
func my_name(...) {}          

Variables:
Built-in simple types: int, float, char, string, bool, none
Compound Types: struct, array

<name> = <expression>
<name> : <type> = <expression>  # first use only
my_int = 10
my_float = 10.3
my_char = 't'
my_string = "ten"
my_bool = true      # true, false are reserved words
delete my_var   # remove from use and clean memory if relevent

When a variable is created, the type is inferred. 
x = 10       # x is inferred to be integer
After creation, a variable has the same type forever.
The program won't compile if an existing variable is assigned a different type
x = 1.0      # error: x is an int, can't assign a float to int

Expressions:
Expressions can contain binary expressions, unary expressions, function calls, literals, etc
x = (1 + 3) * (3 + some_func(10)) + my_array[10] 

Operators: 

Arithmetic operators: 
+, -, *, /, %, ^, **, //
% is modulus, ^ is exponential, ** is integer exponential, // is integer division
Unary minus: - (negates an expression)

All these operators work on integers and floats - the output type depends on operation
int + int -> int
int + float -> float
int / int -> float  # this is different from C, / is true division
int // int -> int   # if you want integer division use //
int ** int -> int   # integer exponential
int ^ int -> float  # floating point exponential

Conditional operations:
and, or, >, <, >=, <=, !=, ==
! is unary NOT operator
All of these expressions return a boolean

Order of operations:
function calls, field access (.), array indexes
{"!", unary -},
{"^", "**"},
{"*", "/", "//", "%"},
{"+", "-"},
{"==", "!=", "<=", ">=", "<", ">"},
{"and"},
{"or"}

Functions: 
All programs start from main function 
func main() -> None { 
    ... 
}

Functions have the following syntax
func <name>(<type> <name>, <type> <name>,...) -> <return-type> { 
    ...
}
If return type is none, you can omit the return type
Functions can be declared in any order

While loops:

while <condition> {
    ...
}

If/else:

if <condition> {
    ...
} else if <condition> {
    ...
} else {
    ...
}
